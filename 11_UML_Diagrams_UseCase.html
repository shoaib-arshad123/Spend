📋 Use Case Overview

Actors:

  • Student User: Primary user who manages expenses, goals, and financial data
  • System: Automated processes including notifications, streak tracking, and AI insights
  • Administrator: System administrator monitoring user activity and system health

Primary Use Cases:

  • Authentication: Sign Up, Log In, Log Out (Cases 1-3)
  • Expense Logging: Manual entry, OCR scanning, voice input (Cases 6-8)
  • Analytics & Insights: Dashboard view, trend analysis, AI advice (Cases 5, 9-10, 13)
  • Financial Goals: Savings goals tracking, subscription management (Cases 11-12)
  • Gamification: Streaks, badges, rewards (Cases 16, 19-20)
  • Personalization: Profile management, theme preferences (Cases 14-15)
  • System Notifications: Budget alerts, subscription reminders (Cases 17-18, 22)
